# References

Terms specific to this image, alphabetized. Common terms (e.g. PassMark, `nice`,
`resource-tracker`, YAML) are defined in the
[glossary](https://docs.sparecores.com/glossary) of the Spare Cores docs, which
also lists the terms each image uses.

- **Kops/s** (Thousand Operations/s): The throughput unit of the PassMark
  database operations test: thousands of operations per second, where higher is
  better.
- **Kstrings/s** (Thousand Strings/s): The throughput unit of the PassMark
  string sorting test: thousands of strings sorted per second, where higher is
  better.
- **Mmat/s** (Million Matrices/s): The throughput unit of the PassMark
  extended instructions test: millions of matrices processed per second, where
  higher is better.
- **Mnums/s** (Million Primes/s): The throughput unit of the PassMark prime
  numbers test: millions of primes per second, where higher is better.
- **Mops/s** (Million Operations/s): The throughput unit of the PassMark integer
  math, floating-point math, and single-threaded tests: millions of operations
  per second, where higher is better.
- **`pt_linux`** (PerformanceTest for Linux): The command-line edition of
  PassMark PerformanceTest for Linux on x86-64 and Arm64 processors. It runs the
  CPU and memory tests of PerformanceTest in a terminal interface, can run them
  unattended, and saves the results to a YAML file.
  [PerformanceTest Linux](https://www.passmark.com/products/pt_linux/)
